# Envitron — Ridge 36-hour 90/10 percentage evaluation

**Sub-team:** Jenjira Huaisai and Friso Terpstra  
**Purpose:** Isolated follow-up to the 6 October 2026 Envitron feedback.  
**Status:** Preliminary — legacy validation boundary retained for comparability.

## Scope

This folder is the **new 90/10-only experiment**, independent of the existing
`First_Version_Ridge_Regression_15m_Horizon`, `RandomForest_Predict_Production`,
and `Ridge_36h_Experiment` folders. It does not include older experiments.

- **Selected building:** Farm, Envitron building ID in source code
- **Historical data:** 18 June 2025 – 21 September 2026, approximately 460 days / 15 months
- **Resolution:** 15 minutes; **forecast horizon:** 36 hours (144 steps)
- **Approaches:** Persistence, Copy-Yesterday, Ridge, Ridge + Weather
- **Validation:** 90/10 chronological split only
- **Metrics:** MAE (kW), RMSE (kW), NMAE (%), NRMSE (%), MAPE (%)
- **Cleaning:** Negative consumption rows excluded (59 in the original selected dataset)

## Run

From inside `Ridge_36h_90_10_percentage_evaluation/`:

```bash
python3 -m pip install -r requirements.txt
python3 src/ridge_36h_90_10.py
```

The code reads `data/*.csv` and writes only into this experiment's `output/` and `models/` directories.

## Files

- `src/ridge_36h_90_10.py` — runnable standalone 90/10 experiment
- `output/metrics_90_10.csv` — MAE, RMSE, NMAE, NRMSE, MAPE for all four approaches
- `output/metrics_by_horizon_90_10.csv` — 144-step error breakdown
- `output/predictions_selected_horizons_90_10.csv` — selected horizons, **not every forecast pair**
- `output/charts/percentage_metrics_90_10.png` — percentage error comparison
- `output/charts/model_comparison_90_10.png` — MAE/RMSE comparison
- `output/charts/actual_vs_predicted_90_10.png` — 36h horizon actual vs forecast
- `models/` — Ridge model artifacts generated by the script
- `NOTE_Ridge_36h_90_10_percentage_evaluation.txt` — weekly research note

## Reference results (preliminary)

The previously reported **Ridge + Weather 90/10** results were MAE 2.87 kW,
RMSE 3.96 kW, mean actual 12.88 kW, NMAE 22.28%, NRMSE 30.72%, MAPE 23.44%.
The CSV in this package contains the results from the source experiment; rerun
this focused script to reproduce or update them.

NMAE = 100 × MAE / mean actual evaluation consumption; NRMSE is analogous.
MAPE averages absolute percentage errors for actual consumption >= 0.1 kW.
MAE and RMSE are averaged over 144 per-horizon metrics, consistent with the legacy experiment.
**NMAE is not an accuracy score.**

## Research limitation

**The legacy 90/10 split may include training origins whose 36-hour target windows
cross into the test period.** It is intentionally retained here to reproduce
previously reported results. The reported metrics must remain **preliminary**.
For leakage-free final evaluation, purge overlapping training origins and rerun;
results may change. Historical weather at the forecast origin is used; future
weather forecasts are not yet included.

## Data privacy

The included Envitron CSVs are for **local/private use only**. Do not push the
`data/` folder, model artifacts, or row-level predictions to a public GitHub
repository. The `.gitignore` excludes them, but check already tracked files.
